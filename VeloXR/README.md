# VeloXR custom holders and mounts.

[VeloXR](https://gitlab.hrz.tu-chemnitz.de/mut_public/VeloXR) is an XR cycling simulator for multimodal measuremnts. This repo contains CAD filed (created using FreeCAD 1.0.0) and related .stl files for the custom holders created for VeloXR.

The CAD models presented here are designed to integrate an Arduino UNO R3 and spoke magnets seamlessly onto to a standard bicycle. These components can be easily produced using additive manufacturing and consist of the following files:
1. A custom mount for ARDUINO UNO R3 microcontrollers, which secures the Arduino UNO R3 directly to the standard bottlecage mounts on the bicycle frame.
2. A spoke magnet holder, which consist of a "Body" and a "Screw" parts that is used to securely attach magnets (Ø 8 mm x 4 mm height) to bicycle wheel spokes for speed measurements with an Hall sensor.
