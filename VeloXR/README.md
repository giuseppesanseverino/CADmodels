# VeloXR Custom Holders and Mounts.

[VeloXR](https://gitlab.hrz.tu-chemnitz.de/mut_public/VeloXR) is an XR cycling simulator for multimodal measurements. This repository contains the CAD files ([created using FreeCAD 1.0.0](https://www.freecad.org/)) and corresponding `.stl` files for the custom mounting hardware developed for the VeloXR platform.

The CAD models presented here are designed to integrate an Arduino UNO R3 and wheel tracking magnets seamlessly onto a standard bicycle. These components can be easily produced using additive manufacturing and consist of the following files:
1. An [Arduino UNO R3 mount](./ArduinoUNO-R3_BottleCageHolder.stl), which secures the microcontroller directly to the standard bottle cage mounts on the bicycle frame.
2. A spoke magnet holder [body](./MagnetSpokeHolder_Body.stl) and matching [screw](./MagnetSpokeHolder_Screw.stl), which are used to securely attach magnets (Ø 8 mm x 4 mm height) to the bicycle wheel spokes for speed measurements with a Hall sensor.
